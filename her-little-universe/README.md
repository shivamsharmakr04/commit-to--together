# Her Little Universe ❤️

A personalized romantic website built with React + Vite + Framer Motion.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Personalize

Open `src/main.jsx` and edit the `DATA` object near the top:

- `herName`
- `nickname`
- `yourName`
- `secretPassword`
- reasons
- memories
- future plans
- final message

## Photos

Put your photos here:

```text
public/photos/photo1.jpg
public/photos/photo2.jpg
public/photos/photo3.jpg
```

## Music

Put your song here:

```text
public/music/our-song.mp3
```

The music button starts playback only after the user clicks it because browsers block automatic audio playback.

## Deploy

Push the project to GitHub and import the repository into Vercel. Vercel should detect Vite automatically.
