# Commit to Together ❤️

A full-stack invitation maker for proposals, anniversaries, weddings, pre-wedding celebrations, birthdays, and other personal events. People create a custom story page, share its unlisted link, and privately review guest replies using a separate owner link.

## Run the project

```bash
cd her-little-universe
npm install
npm run dev
```

Start the API in a second terminal with `npm run server`. See [`her-little-universe/README.md`](her-little-universe/README.md) for setup, database, privacy, and production details.

## Stack

React and Vite frontend, Node.js API, and SQLite persistence.
